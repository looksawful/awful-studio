# iPhone 17 device asset

Current publishable LOW candidate: **v30**.

The asset is generated and validated in Blender 5.2.1 LTS from `generate_low_v30.py`. Older local draft scripts and renders are development history and are not part of the v30 delivery contract.

## Authoritative v30 files

- `generate_low_v30.py` — Blender source generator.
- `generated/iphone_17_low_v30.blend` — generated Blender scene.
- `evidence/low_v30_validation.json` — geometry and dimensional validation.
- `previews/low_v30/` — diagnostic and presentation renders.
- `export_runtime_v30.py` — canonical GLB and packed Blender exporter.
- `optimize_runtime_v30.py` — pinned Meshopt post-process for web delivery.
- `runtime/v30/` — final runtime package and manifest.

## Geometry contract

Nominal body dimensions are 71.45 × 149.61 × 7.95 mm. The generated body validation must remain within 0.01 mm of these values and must report zero non-manifold edges.

The runtime bounds are intentionally larger in depth than the nominal body because camera optics and controls protrude beyond the body shell. Camera fitting must therefore use loaded world-space bounds rather than nominal product dimensions.

The front sensor composition is explicit: one larger Dynamic Island surface, a darker sensor pill on the left and one round camera on the right. Do not add a second visible circular sensor on the left.

Hardware-control contract: Action, volume and side buttons use capsule-profile geometry with 2.56 mm visible face width and 0.45 mm protrusion; Camera Control is an elongated 3.00 mm face-width control with 0.06 mm protrusion. Do not regress Camera Control to a circular proxy.

## Build and QA

1. Run the v30 generator with Blender 5.2.1 LTS.
2. Confirm `passed: true` in `low_v30_validation.json`.
3. Run the runtime exporter against the generated `.blend`.
4. Run `optimize_runtime_v30.py` to create the preferred Meshopt GLB.
5. Load both variants with Three.js `GLTFLoader` and verify front, rear and three-quarter views.
6. Confirm all four runtime anchors and critical named parts remain present.

The preferred web asset uses Meshopt generated by pinned `@gltf-transform/cli@4.5.0`. Blender's built-in Meshopt path is intentionally not used for v30 because visual QA exposed corruption of the thin front sensor geometry despite a structurally valid file.
