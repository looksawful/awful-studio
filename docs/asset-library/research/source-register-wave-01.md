## F. Reference acquisition policy

For every source URL retained here, the production asset folder should eventually contain a small `reference.json` or `sources.yaml` record with:

- URL;
- source type;
- source title;
- access date;
- what facts were extracted;
- confidence;
- whether the source can be redistributed;
- whether local copies/screenshots are allowed;
- whether a later source supersedes it.

Do not commit copyrighted manufacturer PDFs/images into the repository unless redistribution rights are clear. Store links + derived measurements + our own diagrams instead.
