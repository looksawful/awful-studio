# Triage labels

Canonical state-role mapping:

- `needs-triage` -> `needs-triage`
- `needs-info` -> `needs-info`
- `ready-for-agent` -> `ready-for-agent`
- `ready-for-human` -> `ready-for-human`
- `wontfix` -> `wontfix`

Category roles use the repository's existing labels:

- `bug` -> `bug`
- `enhancement` -> `enhancement`

A triaged issue should carry exactly one category role and one state role unless a maintainer explicitly overrides the workflow.
