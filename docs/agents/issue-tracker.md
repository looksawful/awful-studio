# Issue tracker

Provider: GitHub
Repository: `looksawful/awful-studio`
Remote: `https://github.com/looksawful/awful-studio.git`

## Workflow

- Implementation work and status live in GitHub Issues.
- Read the owning issue before editing.
- Use existing issues instead of creating parallel backlogs.
- Branches use `agent/<issue>-<scope>` unless the issue says otherwise.
- GitHub issue comments are written in English.
- Before stopping substantial work, comment the owning issue with changes, verification, commit SHA, blockers, and exact next steps.
- Pull requests are not an inbound triage/request surface by default.
