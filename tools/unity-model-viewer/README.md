# AWFUL Unity Model Viewer

Internal Unity 6.6 editor tool for browsing AWFUL STUDIO procedural mockups, website 3D models, and client logos in one catalog.

## Requirements

- Unity `6000.6.1f1`
- Blender `5.2.1 LTS`
- PowerShell 7 (`pwsh`)
- ImageMagick (`magick`)
- Local checkout of `looksawful.ru` at `%USERPROFILE%\projects\looksawful.ru`

## Sync assets

```powershell
pwsh ./Tools/sync-assets.ps1
```

The sync regenerates Unity assets from canonical sources. Studio mockups are detached from the scene-only `PRODUCT_CONTENT` fit transform before export, so FBX files preserve the physical dimensions declared in `MOCKUP_SPECS`. Generated FBX/PNG files are intentionally ignored by Git.

## Viewer

Open the project in Unity Hub. The viewer opens once per editor session and is also available at `AWFUL > Model Viewer`.

Catalog groups:
- Studio: procedural product mockups generated by the Blender extension.
- Site: GLB models discovered under `looksawful.ru/public` and converted through Blender.
- Logos: client logo artwork plus canonical names from the website data catalog.
