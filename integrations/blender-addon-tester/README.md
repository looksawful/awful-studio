# blender-addon-tester

Status: reference only.

Upstream: https://github.com/nangtani/blender-addon-tester

Purpose: reference implementation for cross-version Blender add-on testing.

AWFUL currently targets Blender 5.2 LTS, so this tool is not an active dependency. Adopt only if multi-version Blender compatibility becomes an explicit requirement and its added machinery is justified.
